  a non-empty `reason` whenever `passed` is false. Explicit experiment details
  override the measured fallback. The report validity table now includes a
  `Reason` column.

  frozen smoke reader now follows actual transition ownership, normalises
  multi-valued Jira fields, and assigns vote outcomes to the KIP named by the
  vote mail rather than an incidentally mentioned issue. Retrieve-everything
  macro accuracy is `1.0` for W1, W20+rules, and W20+rules+deviation; the shared
  E2 check passes with no failed cadence checks.
- The smoke corpus supplies eight distributed situations. E1 produces five R5
  promotions in the probe window and five complete now/close harm pairs.
  Coverage, leakage, and non-vacuity all pass.
- E6 emits its repetition failure as structured measured evidence, including
  the assessed-group count, threshold, worst group, finite repetition count,
  and the unavailable spread (`null` when fewer than three finite p99 values
  exist). The aggregate primary validity check includes the same reason.
- Builder runtime seed is passed into `HarnessRequest`, persisted as
  `_meta/input.json.builder_seed`, and recorded on usage rows. The fresh
  baseline S3 input metadata and usage both record seed `1`; regression tests
  capture the serialized live-harness request as well.
- The raised synthetic scenario floor is limited to complete ten-event
  clusters, preserving tiny fixtures, and the S3 harness helper no longer has
  an import-order cycle when imported directly.
