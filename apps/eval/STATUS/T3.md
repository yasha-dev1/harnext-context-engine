# T3 probe generators and gold status

## Built

- `src/harnext_eval/probes/gold.py`: independent Python changelog replay and
  raw-JSON in-memory SQLite query implementations of field state as of T,
  reusable cached engines, and singular/batch disagreement reporting.
- `src/harnext_eval/probes/schema.py`: deterministic candidate hashing and
  seeded round-robin stratified sampling into the shared
  `harnext_eval.types.Probe` model.
- `src/harnext_eval/probes/common.py`: replay loading, period validation,
  entity/time normalization, PR qualification, formatting-only exclusion,
  changed-file extraction, and first-two-path-segment module derivation.
- Six generators: `gen_extraction.py`, `gen_temporal.py`, `gen_update.py`,
  `gen_multisource.py`, `gen_code_location.py`, and `gen_abstention.py`.
- `src/harnext_eval/probes/gen.py`: the standalone `python -m` CLI, six-family
  orchestration, canonical Probe JSONL output, and SHA-256 sidecar.
- Synthetic-corpus coverage under `tests/test_probes/` for all six families,
  dual-gold agreement, seeded determinism, update transition/supersession
  constraints, UNKNOWN abstention, multi-PR file union/module derivation, and
  module CLI/checksum output.

## Run

```bash
python -m harnext_eval.probes.gen \
  --replay apps/eval/out/corpus/synthetic.jsonl \
  --out apps/eval/out/probes/synthetic.jsonl \
  --per-family 60 \
  --seed 1 \
  --probe-start 2026-01-01T00:00:00Z \
  --probe-end 2026-03-01T23:59:59Z
```

The sidecar is written beside the JSONL as
`synthetic.jsonl.sha256`.

## Integration contract

- `code_location.gold` is `{"files": sorted list[str], "modules": sorted
  list[str]}`. Modules are the first two POSIX path segments.
- Code-location `source_event_ids` are the qualifying non-formatting PR merge
  events in `(T, T + 14 days]`; multiple PRs are unioned.
- State candidates are kept only when Python and SQLite gold agree.
- The central `harnext-eval probes` command remains T11-owned; this task exposes
  the requested standalone `python -m harnext_eval.probes.gen` entry point.
