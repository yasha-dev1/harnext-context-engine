  delegation in `stores/base.py`.

  `stores`, `run`, and `report` Typer commands.
- Core tests under `tests/test_core/`.

## Stubbed or deferred

- E1–E6 currently return empty `ExperimentResult` objects. A real experiment
  registration replaces its same-name stub.
- Probe, store-layout, and report CLI commands are integration placeholders for
  T3, T5, and T10.
- `StoreHandle.fold()` intentionally requires a layout callable registered by
  T5; T0 supplies only the versioned-store mechanics.
- `AnthropicLLM` requires the optional Anthropic SDK only when that provider is
  explicitly invoked. Offline paths do not import or call it.

None. The extension seams are `register_experiment()` and `register_layout()`.
