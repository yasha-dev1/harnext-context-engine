## What was integrated

- `config.py`, all five profiles, and `cli.py`
  - Added a strict top-level `ExperimentConfig.prices` section with frozen
    model, effective date, input/output, and optional cache prices.
  - Injected the validated price table into the shared `EngineConfig` runtime
    without duplicating it in resolved YAML.
  - Added profile-controlled erosion panel sizes: 60 for the evidentiary S3
    profile and 10 for offline smoke.
  - E2 CLI runs now always build S3 and pass it as `store_handle`; E3 receives
    the configured panel size; manifests receive the frozen numeric prices.
- `e2/run.py`
  - The registry adapter now requires `store_handle.layout == "S3"` for A4 and
    fails if the mandatory A4-A3 contrast row is absent.
  - Code-location probes now contribute file-set F1 to the multisource macro;
    file precision/recall and module hit remain named secondaries.
  - Underpowered bootstrap cells fail closed while retaining the contrast row.
  - Reader dollars use the frozen typed price table.
- `e3/run.py`
  - Every `acc(S,B)` cell now calls E2's evaluator verbatim, including the same
    arm builder, provider tokenizer, reader, leakage gate, budget accounting,
    and grading path. S3 therefore runs as literal A4 via `INDEX.md` traversal.
  - Equal-budget evidence records measured versus no-fill applicability and the
    actual ±10% result.
  - E3 validity is one fail-closed conjunction covering the shared E2 floors
    and audits plus same-input, leakage, budget, S1 review, S4 fairness, seed
    reliability, builder failures, and erosion evidence.
  - Erosion freezes one family-balanced checkpoint-safe panel, re-golds every
    template at all five checkpoints, requires the entire panel/five-family
    matrix at every checkpoint, and emits no slope if any checkpoint is
    incomplete. Reduced smoke panels are explicitly N/A for the 60-probe gate.
- `e5/run.py` and `stores/fake_usage.py`
  - W20+rules+deviation uses the real R5 score, frozen threshold, and the R5
    `eligible` guard outcome before causal budget admission; guard-ineligible
    events cannot enter the fast lane.
  - Cadence stores retain their actual E2 arm (`A4` for S3, otherwise the
    layout), so no cadence accuracy outcomes are discarded.
  - Frozen E2 validation evidence is propagated and published per cadence in
    `e2_checks.csv`; smoke-only audits are N/A while structural failures remain
    visible.
  - Usage accounting recursively reads the authentic nested SDK schema,
    requires input/output tokens and an exact model ID, rejects failed or
    malformed records, and recomputes dollars only from config-frozen prices.
    Deterministic fake rows are explicitly labelled projections and obtain
    their prices from the same config.
  - The E5 point estimand is the literal `cost_1k(W20+rules) / cost_1k(W1)`.
    The primary value and interval are suppressed unless equal-accuracy and all
    cost-CI/validity gates pass; the ungated ratio remains diagnostic only.
- Regression tests were updated/added under `test_core`, `test_e2e3`,
  `test_e4e5`, and `test_grade` for the mandatory A4 row, shared E3 path,
  fixed erosion templates, multisource F1, R5 guard rejection, nested usage,
  config-derived fake pricing, and primary suppression.
