## Built

- `src/harnext_eval/agents/reader.py`
  - Fixed read-agent system prompt, provider selection, exact token-budget
    truncation, UNKNOWN behavior, citations, token/tool/latency accounting.
- `src/harnext_eval/e2/arms.py` and `e2/__init__.py`

## Run

```bash
uv run pytest apps/eval/tests/test_e2e3 -q
uv run ruff check apps/eval
uv run pyright apps/eval/src apps/eval/tests
```

E2 writes `answers.jsonl`, `metrics.csv`, `contrasts.csv`, and `gate.csv` to
its supplied output directory. E3 writes `curve.csv`, `health.csv`,
`erosion.csv`, `cost.csv`, and `contrasts.csv`.
