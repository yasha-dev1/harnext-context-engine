# T4 graders and store-health status

## Built

- `src/harnext_eval/grade/exact.py`: deterministic Unicode/case/whitespace,
  ticket-key, version-string, and explicit `UNKNOWN` normalisation. Results
  retain both normalised strings.
- `src/harnext_eval/grade/claims.py`: one-pass gold decomposition, bidirectional
  claim entailment precision/recall/F1, a deterministic `FakeLLM` path, and a
  run-twice agreement helper.
- `src/harnext_eval/grade/links.py`: normalised cited-key set precision,
  recall, and F1.
- `src/harnext_eval/grade/localisation.py`: Agentless-superset `file_hit@k`,
  file recall/precision, and module hit using the first two path segments.
- `src/harnext_eval/grade/action.py`: available-field action exact scores,
  assignee/reviewer hit@3, required-ID coverage, E4 action-quality composite,
  LCS-based ROUGE-L, and a position-swapped stable pairwise judge.
- `src/harnext_eval/health/store_health.py`: materialised-store file/byte/entity
  measurements; over-cap, INDEX resolution, dangling path/entity reference,
  MinHash fact-duplication, and global/per-entity supersession leakage checks;
  reviewable detail dictionary plus scalar CSV row.
- Package exports in `grade/__init__.py` and `health/__init__.py`.
- Hand-built grader and planted-defect tests under `tests/test_grade/`.

## Run

```bash
uv run pytest apps/eval/tests/test_grade -q
uv run ruff check apps/eval/src/harnext_eval/grade apps/eval/src/harnext_eval/health apps/eval/tests/test_grade
uv run pyright apps/eval/src/harnext_eval/grade apps/eval/src/harnext_eval/health apps/eval/tests/test_grade
```

## Stubbed or deferred

- No grader or health metric is stubbed. Real claim/judge quality still depends
  on the selected `LLMProvider`; all offline fake-provider behavior is fully
  deterministic.
- Experiment-level aggregation, CSV writing, and CLI wiring remain with the
  owning E2/E3/E4 and integration tasks. T4 returns CSV-compatible scalar rows.

## Integration questions

- None. Public entry points are exported from `harnext_eval.grade` and
  `harnext_eval.health`; every grade entry point returns T0's `GradeResult`.
