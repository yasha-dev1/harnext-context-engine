# T6 — E1 routing status

## Built

- `src/harnext_eval/e1/labels.py`
  - Six strict post-*t* outcome labelling functions: committer reply within one
    hour, resolution within 24 hours, later priority raise, linked PR within 24
    hours, revert within 48 hours, and later Blocker/Critical declaration.
  - The candidate event is not passed to a labelling function, structurally
    enforcing the temporal firewall.
  - Sparse weighted generative label model returning `P(urgent)` and estimated
    LF accuracy, coverage, overlap, conflict, plus declared-vs-outcome agreement.
- `src/harnext_eval/e1/features.py`
  - Deterministic incremental feature fold per shared `baseline_keys`.
  - Log gap, robust 5-minute/1-hour count ratios against a four-week five-minute
    bucket history, type-mix JS divergence, actor/subject novelty, priority,
    money, and time-of-day bucket.
  - Rejects out-of-order input; features at *t* use only state available by *t*.
- `src/harnext_eval/e1/policies.py`
  - Shared replay-driver `RouterPolicy` shape (`rules(event)`, `score(event)`).
  - R0 random, R1 rules, R2 global z/HBOS, R3 per-key robust gap z, R4 per-key
    full-vector HBOS without guards, R5 rules + HBOS + volume + confirmation,
    R6 per-key LOF, and R7 always-fast.
  - Exact stable monthly top-budget admission and a tuning-only theta diagnostic.
- `src/harnext_eval/e1/score.py`
  - Recall/precision at budget, per-source/full-vs-rule-negative aggregation,
    discrete buffered VUS-PR, discrete Huet affiliation zones, situation delay,
    NAB-like low-FN score, random/always sanity scorers, label flips and onset
    jitter.
- `src/harnext_eval/e1/calibration.py`
  - Equal-count decile urgency rates, Spearman rho, and lift over rules.
- `src/harnext_eval/e1/run.py`
  - Rolling month-ahead evaluation with earlier-month fitting and tuning-only
    thresholds, policy/budget/source/population output, robustness tables, E1
    validity checks, registry registration, and T10 chart-hook integration.
  - Writes `scores.parquet`, `metrics.csv`, `calibration.csv`,
    `label_diagnostics.csv`, `robustness.csv`, `attribution.md`, and `harm.csv`.
- `tests/test_e1/`
  - Ten tests covering truncation causality, strict post-*t* labels, all R0–R7
    policies, exact budget capacity, known metric/calibration cases, sanity
    floors, rolling output, registry registration, and live chart hooks.

## Stubbed or deferred

- The Phase-2 S3 action-quality harm check needs the store and E4 action grader.
  `harm.csv` is emitted with its final schema but no rows; this is not used by the
  E1 primary result.
- `pandas.to_parquet` is used when `pyarrow` or `fastparquet` is installed. T0's
  package dependencies currently include neither. In that environment E1 writes
  pandas table-JSON at `scores.parquet` and a
  `scores.parquet.format.json` marker. T11 should add a workspace Parquet engine
  to make the artifact native Parquet in the integrated run.
- Onset jitter helpers are complete, but the T0 synthetic corpus has no explicit
  situation-onset table; the rolling run applies label-flip robustness and leaves
  constructed-onset application to the OrgForge corpus integration.

## Integration notes

- `run.py` calls `register_experiment(E1Experiment())`. The T0 CLI/registry does
  not yet import experiment modules during discovery, so T11 must import
  `harnext_eval.e1.run` (or add general lazy discovery) before CLI lookup.
- The T0 synthetic corpus intentionally lacks committer-role and revert events,
  so those LF coverage checks are false on smoke data. The diagnostics correctly
  expose this; the checks become meaningful on R-long.
