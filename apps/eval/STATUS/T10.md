# T10 statistics and report status

## Built

- `src/harnext_eval/stats/__init__.py`, `stats/stats.py`
  - paired mean difference with entity-clustered BCa bootstrap confidence interval
    and leave-one-entity-out acceleration;
  - exact and mid-p McNemar tests over paired correctness or a 2×2 table;
  - Holm–Bonferroni step-down correction;
  - paired-proportion power and sample-size approximations;
  - pass^k and between-seed standard-deviation helpers.
- `src/harnext_eval/report/charts.py`
  - Agg/PNG implementations of all twelve requested charts: `calibration`,
    `operating_curves`, `e2_family_bars`, `e3_curve`, `erosion`, `health_table`,
    `e4_envelopes`, `e5_pareto`, `e6_burst_slo`, `self_amplification`,
    `demand_curve`, and `checks_table`;
  - every public chart documents its plain pandas/dict input columns and returns
    the saved `Path`.
- `src/harnext_eval/report/report.py`, `report/templates/report.html.j2`
  - `build_report(run_dir) -> Path`, with recursive discovery of current
    `eN/seed-N` and experiment-level layouts;
  - manifest, resolved YAML, six-component nudge summary, primary metrics,
    contrast/CI tables, checks, inline base64 PNGs, and relative CSV links;
  - inline CSS and no external web assets;
  - `python -m harnext_eval.report.report <run_dir>` CLI.
- `tests/test_report/`
  - clustered-bootstrap, known McNemar table, Holm ordering, power/pass^k/seed
    spread tests;
  - toy-data PNG rendering for every chart;
  - fake-run report integration coverage.

## Integration notes

- Experiment chart callers should use the column contracts in each chart
  docstring. An output argument may be either a target PNG or a directory, in
  which case the specification filename is selected.
- Checks are discovered from `results.json` (`checks`, `metrics.checks`, or
  `metrics` keys prefixed by `check.`/`checks.`) and from check/gate CSVs.
- The report intentionally tolerates missing manifests/configs and partial runs,
  so T11 can generate reports during smoke runs as experiments finish.
