## What an examiner should know

- F1 is the **cheapest structured comparator** to the LLM arms: if F4-entity/F5 do not beat F1 on
  entity-state families, the LLM adds nothing there (plan row 145 consequence).
- Volume: one folder per entity ever mentioned (hundreds of thousands), two files each; OVERVIEW
  is rewritten on every event so git history is large but the tree is small per entity.
- `changes()` (`31-47`) tolerates three changelog shapes (`changes`, `items`, single `field`) and
  lower-cases field names; a field spelled differently in `meta` would be silently ignored — the
  answerability audit over S-tools does not cover F1, so F1 completeness is unverified.
- `flat()` (`63-64`) replaces `|` in titles with `/` to keep timeline lines parseable.
- Cross-entity links are only the `linked:` list of co-mentioned entities (`95`), not typed
  relations.
