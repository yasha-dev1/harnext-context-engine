## What an examiner should know

- **Official package, unmodified** — but three paper components do not run: reflexion (absent
  upstream), communities (off), BFS/cross-encoder search (recipe choice). Say "Graphiti 0.30.2
  with default `add_episode` and its RRF recipes", not "Zep as published".
- **Builder confound** (README §4): Qwen3-30B-A3B builds this store; Haiku 4.5 builds the file
  stores. The planned second F5 build with Qwen is the control. The smoke build under
  `out/kafka-500-v2/stores/G-graphiti-smoke/` (21 episodes: 133 LLM calls, 238k in / 14k out tokens,
  234 s) is the basis of the cost projection; its own yaml names `gpt-4.1-mini` as the smoke LLM.
- `max_coroutines: 8` parallelises inside one episode only; episodes are strictly sequential
  (`graphiti.py:394-412`), so transaction order equals event order — required for the temporal
  invalidation semantics and for snapshot correctness.
- Search results are facts (edge text) and entity summaries, not raw events; `get_episode(id)`
  returns the verbatim episode so the agent can cite an event id like the other arms.
- Telemetry disabled (`graphiti.py:33`). Identity hash covers config + package versions
  (`graphiti.py:352-356`); a changed config refuses to resume (`386-387`).
